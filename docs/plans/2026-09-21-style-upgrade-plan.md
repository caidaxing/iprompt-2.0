# 样式升级方案(风格基准:1.0 宣纸编辑风)

> 2026-09-21。结论:**保持并深化 1.0 的宣纸+墨黑编辑风**,不引入上游的暗色风。
> 问题不是风格选错,而是 2.0 新页面只做到"能用",没达到 1.0 的设计密度与一致性。

## 诊断(浏览器实拍)

| 页面 | 状态 |
|---|---|
| 首页/案例库/详情 | ✅ 1.0 打磨过,有质感 |
| 工作台 | ❌ 未登录时案例列表显示"没有匹配的案例"(实际是 API 401)、生成按钮可点但点了才报 401、布局空无锚点 |
| 首页 | ❌ 主 CTA"开始 AI 匹配"指向 1.0 占位页;无 2.0 新板块入口 |
| 对比/模板/技能 | ⚠️ 内容对但排版平,卡片 hover 弱,与 1.0 的细节密度有差距 |

## 改动清单

### P0(功能性体验修复)
1. `/studio` 改为服务端守卫:未登录 → redirect `/login`(与 `/me/generations` 同模式),彻底消灭坏空态
2. 首页 hero CTA:"开始 AI 匹配" → "进入 AI 工作台"(指向 /studio)
3. 首页新增「2.0 板块入口区」:AI 工作台 / 模板库 / 2.5 对比 三张入口卡(编辑风,hover 抬升)

### P1(排版充实)
4. 工作台右栏空态:加 3 张案例示例图锚点(取自精选案例),弱化"空白感"
5. 模板卡片 / 入口卡:统一 hover 抬升(`hover:-translate-y-0.5 hover:shadow-md`)与过渡
6. 对比页区块间距与 1.0 节奏对齐(py-10 体系)

### 设计 token(全站约定,不再逐页发明)
- 主按钮 `bg-ink text-paper`;次按钮 `border border-ink`;幽灵按钮 `text-ink-mute hover:text-ink`
- 卡片 hover:`hover:border-ink hover:-translate-y-0.5 hover:shadow-md transition-all`
- 页头节奏:`eyebrow(10px 字距宽)` → `serif-title(2xl)` → `text-sm text-ink-soft` 说明
- 空态:虚线框 + 居中 `text-ink-mute` + 引导链接
