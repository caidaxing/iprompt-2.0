# iPrompt Studio UI 视觉升级设计

## 目标

在不改变现有业务流程和数据结构的前提下，把 iPrompt Studio 升级为简约、克制、有编辑出版物质感的东方极简界面。

## 视觉方向

- 保留米白宣纸底、墨黑正文、衬线大标题。
- 以细线、编号、留白和非对称网格建立层级，减少普通 SaaS 卡片感。
- 使用低饱和青灰作为主强调色，朱砂色只用于少量状态或重点操作。
- 首页采用品牌型双栏首屏；探索页采用侧重内容的精选区和案例网格；AI 匹配页采用安静的输入工作台。
- 统一圆角、边框、按钮、标签、焦点态和响应式间距，桌面与移动端保持同一语言。

## 页面范围

1. 全局：导航、页脚、背景纹理、排版 token、按钮/标签/输入/卡片基础样式。
2. 首页：增强品牌标识、首屏层级、案例视觉框、信息统计和装饰细节。
3. 探索页：更清晰的分类导航、搜索栏、精选案例、网格卡片和分页。
4. 详情页：强化图片与提示词的双栏关系，提升复制和收藏操作的可见性。
5. AI 匹配页：加入步骤轨道、示例需求和更明确的订阅区，但保持占位状态。

## 约束

- 不修改 API、Prisma 模型、认证和业务逻辑。
- 不引入新的图片依赖；继续使用现有案例图片。
- 保留现有路由和核心文案，保证既有 E2E 流程不受影响。
- 视觉稿中的复杂插画只用 CSS 轻量装饰实现，不把概念图作为生产 UI 背景。

## 验证

- 运行 Vitest 15 项单测。
- 运行 Next production build，确认 TypeScript 和 Tailwind 编译无误。
- 通过本地健康检查确认服务仍返回 200。
- 检查首页、探索页、详情页和 AI 匹配页的桌面/窄屏布局。
